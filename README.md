# Scout

Поиск и сравнение поставщиков продуктов и упаковки для ресторанов. Сделано для второй части тестового задания Goulash.tech.

## Что умеет

- Ищет по категории, городу или фразе вроде «сыры для пиццы в Екатеринбурге».
- Показывает условия, контакты и ссылки на источники. Объясняет оценку поставщика.
- Сравнивает до четырёх компаний рядом.
- Готовит письмо с вопросами о недостающих условиях. Сам письма не отправляет.
- Сохраняет выбранных поставщиков, заметки, статусы и полученные цены. Их можно выгрузить в CSV.

## Запуск

Демо на GitHub Pages работает без сервера приложения: браузер загружает снимок базы и выполняет поиск локально. Для поиска, сравнения и шорт-листа нужен JavaScript.

Для локальной сборки нужны Python 3.12+ и [uv](https://docs.astral.sh/uv/). Ключи API и повторный сбор данных не нужны.

```sh
uv sync --frozen
uv run python tools/build_pages.py --base-path /food-suppliers/ --output dist/food-suppliers
uv run python -m http.server 8000 --directory dist
```

Открыть http://127.0.0.1:8000/food-suppliers/. Каталог вывода должен быть новым. GitHub Actions собирает и публикует сайт при обновлении `main`.

### Режим с backend

Python backend сохранён. Флаг `config.mode` в `scout/static/config.js` выбирает источник данных:

- `static` — JSON-снимок и поиск в браузере. Сборщик Pages записывает этот флаг в выходной каталог.
- `backend` — запросы к FastAPI. Это значение по умолчанию в исходниках; запустите приложение:

```sh
uv run uvicorn scout.web:app --host 127.0.0.1 --port 8000
```

Открыть http://127.0.0.1:8000. В этом режиме поиск работает и без JavaScript. Сам GitHub Pages не запускает Python: для backend-режима нужен отдельный хостинг приложения, одной смены флага на Pages недостаточно.

Заметки хранятся в браузере отдельно для каждого адреса сайта и автоматически между адресами не переносятся.

## Данные и ограничения

В базе 86 поставщиков, найденных на публичных сайтах. Сбор от 13.10.2026, реестр МСП от 10.09.2026. Целевые города: Екатеринбург и Москва. Категории: мясо, рыба, молочные продукты, овощи, бакалея, азиатские продукты, напитки и упаковка.

| Что найдено | Компаний |
|---|---:|
| Телефон или почта | 85 |
| Цены | 34 |
| Минимальный заказ | 46 |
| Условия доставки | 72 |
| Упоминания документов | 46 |
| ИНН совпал с записью ЕГРЮЛ | 38 |

Пустые поля не заполняются выдуманными значениями. Цены и наличие нужно уточнять у поставщика. Документы указаны со слов сайтов; действительность сертификатов не проверялась. Совпадение ИНН с ЕГРЮЛ не подтверждает, кому принадлежит сайт.

Приложение ищет в сохранённой базе, а не в интернете. Шорт-лист хранится только в текущем браузере. Общей работы команды и синхронизации пока нет. Контакты `bubon-horeca.ru` найти не удалось: при повторном обходе сайт был недоступен.

Отчёты о данных: `data/build_report.json` и `data/quality_report.json`. Перед использованием контактов в рабочей системе нужны проверка персональных данных и условий источников.

## Как устроено

FastAPI, Jinja, SQLite и обычный JavaScript. Статическая сборка использует те же шаблоны для карточек и экспортирует данные из SQLite в JSON. В браузере работают словарь категорий, поиск по префиксам слов и ранжирование; в backend-режиме текстовый поиск использует FTS5.

Оценка складывается из соответствия запросу, географии, сведений о юрлице и полноты условий. Это способ упорядочить список, не гарантия надёжности компании. Тесты сравнивают результаты и оценки двух режимов на контрольных запросах.

LLM используется при сборе: ищет сайты и извлекает условия. Во время работы приложения модель не вызывается. Backend, JSON API и MCP используют `scout/service.py`; браузерный поиск — `scout/static/static-source.js`.

- `/about/`: как считаются баллы и откуда взяты данные.
- `/docs` и `/healthz`: API и проверка сервера, только в backend-режиме.

MCP по stdio:

```sh
uv run python -m scout.mcp_server
```

Инструменты: `search_suppliers`, `get_supplier`, `draft_request`. Ресурс `scout://taxonomy` содержит категории и города.

## Повторный сбор

Для запуска демо этот шаг не нужен. Сбор требует сети и авторизованного Claude CLI с доступной квотой. Скачайте ZIP [реестра МСП ФНС](https://www.nalog.gov.ru/opendata/7707329152-rsmp/) в `data/raw/rsmp.zip`, затем:

```sh
uv run python -m pipeline.rsmp
uv run python -m pipeline.discover --workers 2
uv run python -m pipeline.fetch
uv run python -m pipeline.extract --workers 2
uv run python -m pipeline.contacts
uv run python -m pipeline.build
uv run python -m pipeline.audit
```

Исходный реестр, кеши и логи не включены в git. Сборщик проверяет robots.txt, делает паузы между запросами и не обходит CAPTCHA. После пересборки базы заново соберите статический сайт или перезапустите backend.
