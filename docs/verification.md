# Проверки Scout

Результаты от 13.10.2026:

- `uv run pytest -q` — 42 теста прошли.
- `uv run python -m pipeline.audit` — все ссылки на источники входят в список страниц соответствующего поставщика.
- Все 86 карточек поставщиков открываются без серверных ошибок.

## Покрытие тестами

| Файл | Что проверяется |
|---|---|
| `tests/test_core.py` | Разбор запроса, поиск, фильтры и оценка поставщиков |
| `tests/test_web.py` | HTML-страницы, JSON API, источники, CSV, некорректные параметры и 404 |
| `tests/test_e2e.py` | Поиск и сортировка, сравнение до четырёх поставщиков, шорт-лист, сохранение заметок и цен, выгрузка CSV, редактирование черновика письма |
| `tests/test_mcp.py` | Запуск MCP по stdio, вызов инструментов и чтение ресурсов |

Браузерные тесты выполняются в Chromium. Проверяются ширины окна 390 и 1440 px, переключение темы, поиск без JavaScript и отсутствие ошибок JavaScript. Письма поставщикам не отправляются.

## Запуск

Из корня репозитория:

```sh
uv sync --frozen
uv run playwright install chromium
uv run pytest -q
uv run python -m pipeline.audit
```

Тесты сами запускают временный сервер. Снимки карточки поставщика сохраняются в `test-results/supplier-390.png` и `test-results/supplier-1440.png`.

## Ограничения

- Safari, Firefox и физические мобильные устройства не проверялись.
- Проверка ссылок подтверждает структуру данных, а не достоверность сведений на сайтах.
- Актуальность цен, действительность сертификатов и правовые основания использования контактов требуют отдельной проверки.
